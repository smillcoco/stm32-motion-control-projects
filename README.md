# STM32 运动控制项目集

包含动态靶标视觉伺服云台跟踪系统和多任务实时调度的四轴飞行控制与故障保护系统。

## 项目一：动态靶标视觉伺服云台跟踪系统

外部视觉模块通过 USART1 输出坐标，STM32 完成坐标解析、PID 控制和舵机/底盘驱动。包含 MPU6050 DMP、编码器测速、电机 PWM、OLED 和超声波。视觉识别算法不在仓库中。

## 项目二：多任务实时调度的四轴飞行控制与故障保护系统

飞控端使用 FreeRTOS，结合 SI24R1 2.4G、MPU6050、VL53L1X 和电池 ADC，完成无线通信、姿态处理、滤波、定高和电机控制。遥控器负责摇杆采集、按键微调、OLED 显示和无线发送。

## 技术点
- 位置式 PID、串级 PID、低通和卡尔曼滤波
- UART、I2C、SPI、ADC、PWM、定时器
- Keil MDK5
