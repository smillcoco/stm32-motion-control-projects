# 云台固件

## 项目目标

接收外部视觉模块发送的目标坐标，通过 PID 计算舵机云台控制量，使云台持续对准目标。

## 控制流程

外部视觉模块通过 USART1 发送 x,y 坐标；STM32 解析坐标并采集标定点、目标中心和当前位置；位置式 PID 计算 X/Y 输出；经过限幅后生成舵机 PWM。

## 主要模块
- USART1 坐标接收与协议解析
- 四边形标定点及中心点采集
- Position_X_PID、Position_Y_PID 位置控制
- 舵机 PWM 输出和角度限幅
- MPU6050 DMP 姿态读取
- 按键模式切换和 OLED 状态显示

## 项目边界

仓库不包含摄像头驱动和视觉识别算法，STM32 侧只负责坐标输入后的云台闭环控制。
